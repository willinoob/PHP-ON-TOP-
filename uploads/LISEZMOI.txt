PHOTOS DES ANNONCES — IMPORTANT POUR TOUTE L'ÉQUIPE
====================================================

Si les images s'affichent en BLANC / gris chez toi :
  1. Vérifie que ce dossier uploads/ contient bien les fichiers .jpg
  2. Fais un git pull pour récupérer les images depuis le dépôt
  3. Dans phpMyAdmin → base bd_blogmoteur → exécute :
     sql/fix-chemins-photos-relative.sql

Le chemin en base doit être : uploads/peugeot_208.jpg
(pas /blogmoteur_annonces/uploads/... qui ne marche que sur un seul PC)

Nouvelles photos uploadées via le formulaire → enregistrées automatiquement en uploads/nom.jpg
